# HA StreamCinema Add-on Repository

Home Assistant add-on repository for StreamCinema API.

The add-on itself lives in:

```text
streamcinema/
```

Use this repository URL in Home Assistant Add-on Store:

```text
https://github.com/pavelvraj/ha-streamcinema
```

See the full add-on documentation in [streamcinema/README.md](streamcinema/README.md).
